# Repository Guidelines

This repository is a Salesforce expense management package. All source code is under `salesforce-port/`.

- Deploy and test from `salesforce-port/` using Salesforce CLI (`sf`).
- API version **60.0** for metadata and Apex.
- See [`salesforce-port/MIGRATION_TRACKER.md`](salesforce-port/MIGRATION_TRACKER.md) for conventions and wave status.
- Do not reintroduce React Native application code at the repo root.
